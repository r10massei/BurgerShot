- Burger Shot -

Sobre o projeto
O Burger Shot é um site desenvolvido para representar uma hamburgueria fictícia inspirada na franquia Grand Theft Auto (GTA).
O projeto apresenta uma página web com identidade visual própria, voltada para a divulgação da hamburgueria e de seus produtos.

Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (caso utilizado no projeto)

Como visualizar o projeto
1. Acesse o repositório no GitHub.
2. Baixe os arquivos do projeto.
3. Abra a pasta no Visual Studio Code.
4. Abra o arquivo index.html em um navegador.
